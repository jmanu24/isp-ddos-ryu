    Recursos por VM y proceso
    CPU, memoria, disco y procesos dentro de cada VM; CPU Ready del hipervisor ESXi.

    Comparar selección
    Cada grupo conserva capacidad, duración, ejecución, contexto y política registrados. La media principal da el mismo peso a cada semilla. Eventos y ventanas no se cuentan como repeticiones independientes. La cuota entregada usa bytes de aplicación TX+RX; no representa pérdida de paquetes del enlace.
    Distribución por grupo
    Cada punto es la media de una semilla; la línea representa la media equilibrada del grupo.
    Diferencias con el mismo plan
    Diferencia = comparación − referencia. En porcentajes se expresa en puntos porcentuales. La coincidencia del plan no verifica por sí sola todas las condiciones.
    ReferenciaComparaciónSemillaDiferenciaParidad registrada
    Cómo interpretar la estadística
    Los IC 95 % usan t de Student sobre medias de semillas y suponen independencia y comparabilidad. No establecen causalidad. Una sola semilla no permite estimar el intervalo; resultados idénticos no demuestran incertidumbre nula. La estimación de semillas adicionales es orientativa y utiliza variabilidad piloto. Los intervalos no se recortan a 0–100 % para ocultar su amplitud.
